Лабораторная работа №3 — PHP
Вариант 18. Длительность звонков.

Правила:
- Длительность в секундах, диапазон 0..7200.
- Значение 0 — пропустить (continue).
- Значение -1 — маркер остановки (break).
- Значения < 0 (кроме -1) или > 7200 — ошибка (throw).
- Пустой массив или отсутствие данных — ошибка (throw).

Алгоритм:
1. Перебор массива foreach.
2. Пропуск нулей, остановка на -1.
3. Валидация типа и диапазона.
4. Подсчёт суммы, количества, максимума.
5. Среднее через арифметику.
6. Второй проход for — подсчёт длинных звонков (>= 1800 сек).
7. Классификация средней длительности через match.
8. Классификация суммарной нагрузки через if/elseif/else.
9. HTML-вывод + try/catch/finally.

Запуск:
- Скопировать папку lab-03 в C:\laragon\www\
- Открыть http://localhost/lab-03/ в браузере.
